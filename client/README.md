# Client

Next.js frontend for the Nationwide Sales Distribution System.

## Setup

1. `npm install`
2. Copy `.env.local` and set `NEXT_PUBLIC_API_URL` (server URL)
3. `npm run dev`

## Scripts

- `npm run dev` — dev server
- `npm run build` / `npm run start` — production build/serve
- `npm run lint` — eslint
- `npm run test:e2e` — Playwright e2e tests (auto-boots dev server)

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · TanStack Query
